# PROYECTOS

Esta es la carpeta que tenes que usar para cargar proyectos.

Cada proyecto va en una carpeta propia:

```text
PROYECTOS/
  Ejemplo/
    proyecto.md
    fotos/
      portada.jpg
      galeria-1.jpg
      galeria-2.jpg
```

## Imagenes necesarias

Para cada proyecto, carga minimo 3 imagenes:

- `portada.jpg`: imagen principal para listados, grillas y tarjetas.
- `galeria-1.jpg`: primera imagen del detalle.
- `galeria-2.jpg`: segunda imagen del detalle.

Si queres agregar mas fotos, segui el patron:

```text
galeria-3.jpg
galeria-4.jpg
galeria-5.jpg
```

## Datos del proyecto

Edita el archivo `proyecto.md` de cada carpeta.

Campos principales:

- `titulo`
- `slug`
- `categoria`
- `ubicacion`
- `anio`
- `cliente`
- `arquitecto`
- `superficie`
- `estado`
- `portada`
- `galeria`

Despues completa los textos:

- `Resumen`
- `Descripcion`
- `Concepto`
- `Resultado`

## Proyecto ejemplo

Ya hay un proyecto creado:

```text
PROYECTOS/Ejemplo/proyecto.md
```

La web ya lee esta carpeta. Cuando agregues otro proyecto, copia `Ejemplo`, cambia el nombre de la carpeta, edita `proyecto.md` y pone las fotos en `fotos`.
